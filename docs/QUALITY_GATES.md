# 质量闸门 | Quality Gates

| 阶段 | 最低通过条件 | 不通过时的处理 |
|---|---|---|
| G0 立题 | 定义人群、问题、主要结局、设计、版本和未知事项 | 只形成工作假设，不承诺分析结论 |
| G1 检索 | 真实文献有来源和核验状态，方法可复现 | 保留检索式，标记“尚未完成检索” |
| G2 研究方案 | 预设终点/分析/样本或事件论证/关键偏倚控制 | 提交方法学待办，不做性能或效应承诺 |
| G3 写作 | 结果可追溯到真实数据，文献支持各自的论点 | 用明确占位符，禁止补造结果 |
| G4 模拟审稿 | 每条重大问题都有定位、风险说明和可执行回应 | 不得宣称问题已解决 |
| G5 投稿前 | 作者复核图表、数据、伦理、引用、声明和目标期刊要求 | 仅交付修订草案，不称为“可投稿终稿” |

**检查四类常见风险：**

- 真实性：引用、原始结果、样本数、伦理审批与注册信息。
- 内部一致性：题目、摘要、正文、表格、图例、附录中的数字和定义。
- 统计有效性：研究类型与分析匹配、混杂和缺失、过拟合、模型验证和数据泄漏。
- 医学安全：临床解释谨慎，未获得合理权限不得处理个人敏感信息。

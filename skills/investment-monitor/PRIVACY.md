# Public Release Privacy Checklist

Before publishing or updating this Skill, confirm:

- [ ] No personal net worth, income, household expenses or individually identifiable financial goals.
- [ ] No personal allocation percentages, contribution amounts, balances or transaction history.
- [ ] No brokerage/exchange identifiers, identity-linked wallet addresses, API keys, tokens or passwords.
- [ ] No screenshots or exports from personal financial accounts.
- [ ] Example configuration contains placeholders only.
- [ ] Reports use synthetic examples and label them as examples.
- [ ] Data-provider terms and licenses permit intended use.
- [ ] The Skill does not claim guaranteed returns, verified backtests or automatic execution without evidence.

Keep private configuration in a local file excluded by .gitignore. If a secret is committed, deleting it from the latest file is insufficient: revoke or rotate it and follow the host's history-removal guidance.

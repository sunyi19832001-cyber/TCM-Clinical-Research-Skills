# Quick Start | 三个演示命令

这些是**虚构教学情境**，不涉及任何真实患者、机构、论文结果或已采集样本。

## 1. 文献策略

```text
请读取 skills/deep-research/SKILL.md。
教学题目：一个新编制的中医症状量表，是否已有类似测量工具？
请制定 PubMed 检索策略和证据矩阵空表，标出必须现场核验的来源。
如无法联网，请只提供检索计划，不要说已完成检索。
```

## 2. 写作提纲

```text
请读取 skills/academic-paper/SKILL.md。
使用一份假设的前瞻性观察研究方案（没有任何真实结果），
写出 Introduction 和 Methods 的提纲，以及 Results 占位符列表。
不要生成任何虚构效应量、病例数或伦理信息。
```

## 3. 模拟审稿

```text
请读取 skills/academic-reviewer/SKILL.md。
我将提供一份经过授权且不包含个人信息的研究方案。
从临床、统计、证候测量和反方审稿四个视角指出问题，
按致命、重大、一般排序，并为每个问题标出方案位置。
```

## 建议的结果命名

`01_search_strategy.md`, `02_evidence_matrix.csv`, `03_protocol_review.md`, `04_manuscript_outline.md`, `05_review_log.md`。
